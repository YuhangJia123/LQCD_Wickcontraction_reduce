# Benchmarks

These documents record timing, peak memory, contract/network counts, and the exact measurement scope.

- [`optimization_benchmark.md`](optimization_benchmark.md) and [`optimization_benchmark_zh.md`](optimization_benchmark_zh.md): generic reducer timing and correctness checks.
- [`../data/benchmark_20261015/ppn_block.md`](../data/benchmark_20261015/ppn_block.md): normal-wick-block ppn measurement.
- [`reference/`](reference) contains the fixed UCA and recursive reference implementations used by the comparison data.
- Machine-readable runs remain under [`../data/`](../data).

Numbers from orbit construction, generic basis reduction, fused `nlist`, and literature state-block counts are different metrics; compare only within the stated scope.
