# Reports and research material

This directory stores the final report, algorithm notes, implementation records, validation evidence, benchmarks, and experiment data. The root README is the project overview, and the Quickstart is the runnable guide; this directory explains the method and records its evidence.

## Entry points

| Need | Location |
| --- | --- |
| Read the current report | [`final/wick_diss_reduce_algorithm_report.md`](final/wick_diss_reduce_algorithm_report.md) |
| Read the PDF or edit the TeX | [`final/wick_diss_reduce_algorithm_beamer.pdf`](final/wick_diss_reduce_algorithm_beamer.pdf), [`final/wick_diss_reduce_algorithm_beamer.tex`](final/wick_diss_reduce_algorithm_beamer.tex) |
| Mathematical algorithms | [`algorithms/mathematics/`](algorithms/mathematics) |
| Implementation notes | [`algorithms/implementation/`](algorithms/implementation) |
| Validation evidence | [`validation/`](validation) |
| Performance benchmarks | [`benchmarks/`](benchmarks) |
| Historical material | [`historical/`](historical) |
| Experiment data | [`data/`](data) |

The executable verification commands are documented in [`verify_code/README.md`](../verify_code/README.md), with a Chinese companion at [`verify_code/README_zh.md`](../verify_code/README_zh.md). The three production kernels are indexed in [`docs/kernels/README.md`](../docs/kernels/README.md).
