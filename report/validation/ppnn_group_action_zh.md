# ppnn 群作用审计

本说明记录对一个拟议的 4He（ppnn）Wick 类群作用进行的可复现轨道计数。它与生产 peram/Dirac reducer 分开；两者采用不同的等价关系。

原始味道配对数为 `6!6!=518{,}400`。对四个汇端重子内部的同味夸克交换取商后，得到 `518{,}400/2^4=32{,}400` 个状态。一个状态由以下标签构成：分配给汇端质子的两个无序源端 `(u)` 对；分配给汇端中子的两个有序剩余 `(u)` 标签；分配给汇端中子的两个无序源端 `(d)` 对；以及分配给汇端质子的两个有序剩余 `(d)` 标签。

测试的群由两个质子和两个中子的源端、汇端交换，以及全局同位旋翻转（p↔n、u↔d）生成。四个重子块交换构成 H ≅ (C₂)^4；同位旋翻转交换质子和中子生成元，因此 |H ⋊ C₂|=32。

Burnside 固定点直方图：

| 固定状态数 | 群元素数 |
| ---: | ---: |
| 32,400 | 1 |
| 576 | 1 |
| 180 | 4 |
| 96 | 4 |
| 24 | 4 |
| 0 | 18 |

因此该作用有 1,068 个轨道。直接枚举得到轨道大小为 4、8、16 和 32 的轨道分别有 4、14、83 和 967 个。作为内置校准，`ppn` 有 360 个状态和 93 个轨道，与文献引用的 ³He 数目一致。

本 `ppnn` 结果没有复现 [arXiv:0912.1383v1](https://arxiv.org/html/0912.1383v1) 报告的 1,107；该文描述了计算机筛选，但未给出明确的生成元列表或保留项列表。[arXiv:1205.0585](https://arxiv.org/html/1205.0585) 记录了 32,400 个 sub-permutation，并引用了 1,107 这一约化数。这个差异意味着当前显式轨道作用本身并不能推导论文中的计数，但不能据此断定论文的计数错误。

运行独立枚举：

```sh
python3 verify_code/ppnn_group_action.py
```

运行回归检查：

```sh
python3 -B -m unittest tests.test_ppnn_group_action
```
