# Validation evidence

This directory contains correctness evidence and fixed audit outputs. The scripts that produce these documents live in [`verify_code/`](../../verify_code).

- `global_block_validation_zh.md`: normal-wick-block certificates and numerical checks.
- `ppn_projected_*`, `ppnn_fixed_*`, `ppnn_group_action_zh.md`: projected-state and group-action audits.
- `*_orbit_*`, `benchmark_orbit_vs_reducer_zh.md`, `check_validation_summary_zh.md`: orbit, crosswalk, and check validation.
- The JSON files in this directory are machine-readable evidence referenced by the reports.

Run the maintained commands from [`verify_code/README_zh.md`](../../verify_code/README_zh.md). Historical counts must be interpreted with the scope stated in each document.
