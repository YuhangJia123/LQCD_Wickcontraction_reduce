# ppn：93 个投影收缩项的含义

## 结论

在本重构中，**93 表示投影前求和的状态块数**，既不是 93 个单独的 raw Wick 收缩，也不是 93 个开放的六 Dirac 指标张量。一个状态块先把三个核子内部同味槽位交换所产生的 8 个带符号 raw Wick 项相加；再将得到的 360 个标签状态按汇端和源端的两个质子重子独立互换分组。

脚本审计的精确约化公式为

$$F_{ppn}=\sum_{s\in S}b_s=\sum_{O\in S/G}|O|b_{s_O},\qquad b_s=\sum_{w:s(w)=s}\operatorname{sgn}(w)\,\langle P,C_w\rangle.$$

这里 `C_w` 是本地代码中的开放指标 Wick 张量；`P` 将它的六个自旋轴投影到 \({}^3\mathrm{He}\) 算符的固定 ppn 电荷分量。每个 `b_s` 汇总 8 个 raw Wick 项。轨道重数 `|O|` 为 2 或 4，因此 93 个代表状态块对应 `6*2 + 87*4 = 360` 个状态块，也就是 `8*360 = 2880` 个 raw 项。

## 状态块为何相等

自旋分量按 `(p1,p2,n)` 顺序为 `(|+,-,+> - |-,+,+>)/sqrt(6)`，源端和汇端相同。它是 [Yamazaki（arXiv:1012.0410）](https://arxiv.org/abs/1012.0410) 方程 (6) 中六项 \({}^3\mathrm{He}\) 插值算符的固定 ppn 分量。只交换一侧的质子重子块时，带符号 Wick 块产生一个负号，自旋投影也产生一个负号，所以 `b_(g s)=b_s`。群为 `S2_sink x S2_source`，其 93 个轨道大小分布为 `{2: 6, 4: 87}`。

这是关于投影后标量状态块的结论。投影前对应的是开放的六自旋指标张量，93 个单 raw 项候选不能重构其完整总和。本地测试验证了这一区别：拟合得到的“轨道和/单 raw 项”比值会随 peram 随机种子变化，用第一个种子的比值预测后续全和时，缩放误差分别为 0.197 和 0.113。相反，8 项状态块的比值与轨道大小最多相差 `1.2e-14`。直接使用整数轨道权重时，三个种子各自的重构误差均低于 `6.7e-17`；用第一个种子的权重重构另外两个种子的全和，缩放误差低于 `7e-17`。

## 698 与 93 为何不同

本地 698 项审计保留完整开放张量 `T_{ABCDEF}=sum_w sign(w) C_w`，其中六个 Dirac 指标都可用，并以约 `1.4e-15` 的残差重构。93 状态块恒等式只在将 `T` 与固定的自旋-味道投影器 `P` 收缩、得到单个标量相关子后成立。投影会丢弃张量分量并允许抵消，因此开放张量的 basis 大小与投影状态块数是两个不同目标。更早的开放张量测试中，93 个单 raw 项候选张成空间的残差为 `0.82-0.86`，见[ppn 93 候选数值张成空间审计](ppn_orbit_numeric_audit_zh.md)。

[arXiv:1205.0585](https://arxiv.org/abs/1205.0585) 也将这两种计数区分开：它把 93 列为较早的、基于对称性的置换数；其统一收缩算法另有 `N_perm` 和 `N_contr` 计数（非相对论 3He 设置的表 8 中为 360 和 3240）。因此，若未先匹配所计对象和收缩阶段，93 或 3240 都不能直接与本地 698 相比较。

脚本还将质子对的自旋三重态与总自旋 1/2 耦合，作为对照进行测试。其局部同位置 pp 相关子在浮点精度内为零，与 Pauli 反对称性相符，因此该通道不用于建立 93 项公式。

## 审计设置

- 投影器：方程 (6) 的固定 ppn 分量 `(|+,-,+>-|-,+,+>)/sqrt(6)`，使用上分量，并同时施加在源端和汇端。
- 比较各项前先投影全部六个开放 Dirac 轴；只有上分量 0 和 1 保留。
- Peram 为相互独立的通用复数同位旋简并矩阵；颜色张量使用 `N_c=3` 的 epsilon 符号。
- 每个种子的直接基准：2,880 次带符号 Wick 收缩。
- 约化计算：93 个代表状态块；每个种子独立重算其底层 744 次 raw 收缩（每块 8 次）。
- 轨道权重是精确整数大小 2 或 4，不是由数值拟合得到。
- 单个 raw Wick 代表的最大轨道残差：`9.969288e-01`；拟合的 raw-93 全和残差：`1.908259e+00`。
- 8-Wick 状态块的最大轨道残差：`7.042687e-15`；独立重算的 block-93 全和残差：`2.325821e-15`。
- 容差 `1e-10` 下完整重构：**通过**。
- 轨道直方图：`{2: 6, 4: 87}`；生成的成员表见 [ppn 投影 93 项映射（中文）](ppn_projected_93_mapping_zh.md)。
- 随机种子：`20261021, 20261022, 20261023, 20261024`；耗时：`22.883 s`。

## 与论文的关系

[arXiv:0912.1383v1](https://arxiv.org/abs/0912.1383v1) 称对 ³He 相关子进行计算机筛选后留下 93 个收缩项，并报告在一个规范场构型上与全和一致。该文没有公开 93 项保留列表或逐项映射。同一讨论另称其零动量汇端重子块可同时计算 `2^N_N=8` 次收缩。本重构解释了一种具体方式，说明 93 个投影状态块如何涵盖 2,880 个项；但由于论文未公开列表，无法断定这里的 ID 就是作者保留的 93 项。

本审计验证的是仓库内置 ppn 夸克算符、指定固定电荷自旋投影、同位旋简并传播子，以及项目模型中的颜色/自旋收缩代数。它不是对原规范场构型计算或论文未公开保留项表的逐位复现。本参考脚本中的 93 个代表状态块展开为 744 次普通 raw `contract` 求值；融合的重子块计算核可能会更高效地评估这些组合。

## 适用范围

数值审计使用仓库内置的 ppn 源/汇算符、同位旋简并的通用复数 peram、`Nc=3` epsilon VVV 张量，以及三个独立随机种子。精确的轨道大小恒等式来自明确的重子块交换和反对称自旋投影；数值运行用于检查该恒等式在代码中的实现。

这给出了一个具体机制：93 个投影后的**状态块收缩**如何重构全部 2,880 个 raw Wick 项。它本身不能证明这些具体状态块和投影就是 arXiv:0912.1383v1 中未公开的 93 项实现。该论文没有列出其保留项；生产代码也尚未加入将每个 8-Wick 状态块作为一个计算核执行的融合实现。

## 复现

在项目根目录安装可选数值依赖：

```sh
python3 -m pip install '.[numeric]'
```

```sh
python3 -B -m verify_code.ppn_projected_93_audit
```

脚本会检查成员覆盖是否精确（`2880` 个 ID 且各出现一次）、状态块大小（均为 `8`）、轨道权重、独立代表重算，以及与直接全和是否一致。
