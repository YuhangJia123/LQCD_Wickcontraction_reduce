# normal ppnn 固定 288 方案验收

本记录只验收第一个已确认的 288 网络布局，不再评分其它布局：

```text
(0,1), (2,5), (3,4), (6,7), (8,11), (9,10)
```

槽位顺序为 `p1=(u0,u1,d2)`、`p2=(u3,u4,d5)`、`n1=(d6,d7,u8)`、`n2=(d9,d10,u11)`。六个 W 使用一个数值传播子类型，W 在每个融合网络中出现六次。所有传播子保留完整四个 Dirac 分量，输出张量为八个开放轴 `(4,)*8`。

## 输入

- 模式：`normal`
- 基础收缩：4,298
- basis 视图：493,992
- 原始 Wick 配对：518,400
- 固定布局的融合项：8,100
- 最终不同 block 网络：288
- W 类型：1
- 输入文件 SHA-256：`f5d7913299420b7898878278e4bd3db31b36929c390a84cb13480d65f0a4410e`

## 验证

符号验证按完整 W 定义展开并通过，`symbolic_verified=true`。数值验证只比较两个最终张量：

1. 原 reducer basis 的全部加权 Wick 总和；
2. 固定 288 个 block 网络及其重构视图的总和。

使用 seed `20261014` 生成完整形状 `(3,4,3,4)` 的随机 normal peram。两边都计算完整八开放轴张量。结果为：

```text
maximum_absolute_error   = 1.9755338862857515e-4
maximum_normalized_error = 4.514685485483913e-14
norm_relative_error      = 2.7408411274602856e-14
```

归一化误差低于 `1e-10`，因此最终 Wick 总和与 block 总和一致。原 Wick 总和耗时约 301 秒，288 网络 block 总和耗时约 211 秒；本次完整计划生成和符号验证耗时约 1101 秒。

机器可读结果位于 `/private/tmp/ppnn_block_run/fixed_288_audit2/report.json`，执行表位于 `/private/tmp/ppnn_block_run/fixed_288_audit2/plan_execution.json`。

该结果证明第一个 288 布局可行。两个 288 布局按用户指定视为等价，因此采用第一个；本次没有把其它布局作为数值比较对象，也没有据此宣称所有可能布局中的全局最优性。
